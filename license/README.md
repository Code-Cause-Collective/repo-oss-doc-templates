# License

A software license is a legal instrument that governs how software may be used, modified, and redistributed.

## Why it matters

A license protects the creator from liability and clearly defines what others are allowed to do with the software—essentially giving the community “permission to play.”

## Common Licenses

| **License Name**                      | **Purpose**                                               | **Typical Use Cases**                                  |
| ------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| **MIT License**                       | Permissive open-source license with minimal requirements  | Open-source libraries, startups, commercial software   |
| **Apache License 2.0**                | Permissive **open-source** license with patent protection | Enterprise-grade open-source projects, cloud platforms |
| **GNU GPL v3**                        | Strong copyleft to keep software open                     | Community-driven open-source software                  |
| **GNU LGPL**                          | Weak copyleft, allows proprietary linking                 | Shared libraries used by open and closed software      |
| **BSD License (2-Clause / 3-Clause)** | Simple permissive open-source license                     | Academic, networking, and system software              |
| **Mozilla Public License 2.0 (MPL)**  | File-level copyleft open-source license                   | Mixed open-source and proprietary codebases            |
| **Creative Commons CC-BY**            | Open content license with attribution                     | Blogs, articles, images, documentation                 |
| **Creative Commons CC-BY-SA**         | Open content with share-alike requirement                 | Wikipedia, open educational resources                  |
| **Creative Commons CC-BY-NC**         | Non-commercial content sharing                            | Personal projects, learning materials                  |
| **Proprietary License**               | Restricts usage and redistribution                        | Paid/commercial software products                      |
| **Public Domain (CC0 / Unlicense)**   | No copyright restrictions                                 | Code snippets, datasets, templates                     |
