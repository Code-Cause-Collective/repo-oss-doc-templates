# Code Of Conduct

A `CODE_OF_CONDUCT.md` file is a document that defines acceptable and unacceptable behavior and explains how violations are addressed within a community or project.

## Examples

> [!NOTE]
> The examples *we* provided are opinionated and intended as guidance. We encourage you to explore other approaches, adapt them to your workflow, and expand upon them to fit the specific needs of your project.

## Tools

### [Contributor Covenant: Interactive Code Of Conduct Builder](https://www.contributor-covenant.org/adopt/)

An interactive tool that helps projects quickly adopt the Contributor Covenant Code of Conduct. It guides maintainers through customizing enforcement guidelines and contact information, making it easy to create a clear, inclusive, and welcoming standard of behavior for contributors.
